About This Project

This website was created for IT 3203 Web Development. The topic is the evolution of the Hypertext Transfer Protocol (HTTP) and how it has changed as the internet has developed.

About Myself

I am a student studying information technology and cybersecurity. This project gave me an opportunity to practice using HTML and CSS to create a website with multiple pages and a consistent design.

Project Goals

  • Explain the history of HTTP and its major versions.
  • Describe important HTTP concepts in simple terms.
  • Practice organizing information across multiple web pages.
  • Use HTML and CSS to create a consistent website layout.
  • Publish the completed website using GitHub Pages.

Technologies Used

  • HTML for the structure and content of each page.
  • CSS for colors, spacing, navigation, and layout.
  • GitHub Codespaces for editing the website files.
  • GitHub Pages for publishing the website.

What I Learned

This project demonstrates how separate HTML pages can be connected through navigation links and styled using one shared CSS file. It also helped me learn more about how HTTP supports communication between web browsers and servers.
