References and Resources

The following sources provide information about HTTP, its development, and the technical features of its different versions. They can also be used to learn more about web communication.

Technical References

  1. Berners-Lee, T. (1991). WorldWideWeb: Summary. World Wide Web Consortium. Early history of the World Wide Web
  2. Fielding, R., Nottingham, M., and Reschke, J. (2022). HTTP Semantics. RFC 9110. Read RFC 9110
  3. Fielding, R., Nottingham, M., and Reschke, J. (2022). HTTP/1.1. RFC 9112. Read RFC 9112
  4. Thomson, M., and Benfield, C. (2022). HTTP/2. RFC 9113. Read RFC 9113
  5. Bishop, M. (2022). HTTP/3. RFC 9114. Read RFC 9114
  6. Iyengar, J., and Thomson, M. (2021). QUIC: A UDP-Based Multiplexed and Secure Transport. RFC 9000. Read RFC 9000

Learning Resources

  • MDN Web Docs: HTTP — An introduction to HTTP concepts and how the protocol works.
  • World Wide Web Consortium: HTTP Protocols — Information about web protocols and their development.
  • RFC Editor — The official publication archive for Internet standards and technical documents.

How These Sources Were Used

The RFC documents explain the technical details of HTTP and its newer versions. The MDN and W3C resources provide additional background that helps explain these concepts in a more accessible way.
